# Docs

- Distribution: HAGLO servers get this repository and the add-on preinstalled by the provisioning stick
  (`ha store add https://github.com/mangfall/addons`, add-on slug `bf5f9957_mangfall-cards`).
- Marketing: https://mangfall.eu/karten presents the cards; the optional newsletter signup there uses
  double opt-in and is never a condition for using the cards (no coupling, GDPR Art. 7(4)).
