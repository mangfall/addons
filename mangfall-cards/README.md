# MANGFALL Karten

26 Dashboard-Karten für Home Assistant in einem ruhigen Design. Sie finden ihre Sensoren selbst –
kein YAML, kein roter Fehlerkasten, alles auf Deutsch.

Zisterne (LEVEL), Energiefluss und Energieverlauf (WATT), Strompreis, E-Auto, Heizung, Raumklima,
Luftqualität, Batterien, Fenster und Türen, Rollläden, Sicherheit, Kameras, Musik, Lichter,
Saugroboter, Mähroboter, Müllabfuhr, Wetter, Termine, Anwesenheit, Verbraucher, Schnellaktionen,
Haus auf einen Blick, Haus-Check und Wasserwaage (FLAT).

Mehr unter [mangfall.eu/karten](https://mangfall.eu/karten).
